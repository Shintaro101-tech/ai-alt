# AI-ALT — Your AI Assistant Language Teachers

英語の授業で使う AI の ALT（Emma / Oliver / Noah / Chloe）。PCのブラウザで開き、プロジェクターに映して使います。
アバター・声・会話のしくみは「洋書トーク」と共通で、中継サーバー（Cloudflare Worker）も洋書トークのものを使います。

## 画面

- **左：ALT** … 「▶ ○○ を呼ぶ」で接続。ALTは自分からは話さず、先生が話しかける（例：「Hi Emma! Can you introduce yourself?」）と、その内容に応じて話し始めます。話すと口が動きます。
  - 🎙 マイクON/OFF（M キー）… 日本語で説明するときなどはOFFに
  - **ALTにお願い** … ボタン（このスライドを説明／例文をボードに／クラスに質問／もう一度ゆっくり）か、入力欄から。声に出さずにALTだけに伝わります
  - 声で聞くときは「Emma, …」と名前を呼ぶ
  - ⏹ 終了 → 「▶ 再開する」で、それまでの会話を覚えたまま戻ってきます
- **右：ディスプレイ**
  - 📑 スライド … PowerPoint（アニメーションつき）や、ここで作ったスライド。ALTは今のスライドの文字とメモを把握しています
  - ✍️ ALTボード … ALTが会話の中で重要表現・例文・質問を書き出します（「Can you write it on the board?」でも可）
    - **図・グラフ**：説明がわかりやすくなるときや「Can you show it in a diagram?」と頼んだときに、ALTが描きます。アプリがその場で描くので、すぐ出て料金もかかりません。
      現実ともしもの世界（仮定法の「距離」）／時間軸（過去・現在・未来、もしもは吹き出し）／棒グラフ・折れ線グラフ／表／ベン図／手順／絵文字カード
    - **スケッチ**：家・キッチン・天気・人物などの簡単な絵を、ALTがその場で線で描きます（数秒）。描いている間、アバターにペンが表示されます。
    - **AIイラスト**：本格的な絵が必要なときだけ、ALTが「It might take about 30 seconds. Do you want me to do it?」と聞き、先生が了承したら作ります（約30秒、1枚ごとに料金がかかります）。待っている間も授業は続けられ、できたらボードに出ます。気に入った絵は「📌 画像ライブラリに保存」で次回も使えます。中継サーバーの POST /illustrations（gpt-image-2.6-flare）を使います
    - **画像**：編集画面の「ALT が見せる画像」に名前を付けて登録した写真・イラストを、ALTが話の流れで出します。先生がボードの「🖼 画像を出す」から出すこともできます（ALTにも伝わります）
  - 💬 スクリプト … 会話がリアルタイムで文字に
  - **🖥 スライドだけ全画面**（F5）… ALTを隠してスライドだけを表示。Esc で戻る

## 学生の英語レベル

授業画面の左（ALTの下）か編集画面で **Pre-A1 / A1 / A2 / A2+ / B1 / B2 / C1** から選びます。
ALTは話すスピード・使う単語・文の長さと文法・1回に話す量をそのレベルに合わせます（台本も意味と文法事項はそのまま、言い方をレベルに合わせます）。
授業中に変えても、次の発言からすぐに切り替わります。

**話す速さ**（レベルの下）：🐢 とてもゆっくり／ゆっくり／レベルどおり。
GPT-Live には速さの設定がないため、レベルと速さから「1分あたり約○語」をALTに指示しています（例：A2+ は約105語、ゆっくりで約90語、とてもゆっくりで約80語）。スライドをめくるたびに「ゆっくり話す」ことも念押しします。

## マイク・スピーカーの確認

授業の前に、教室の「🎧 マイク・スピーカーの確認」で使う機器を選んで試せます。ALT を呼んだあとも、ALT の下の「🎧 マイク・スピーカー」からいつでも切り替えられます（全画面表示中は出ないので、Esc で戻ってから）。

- マイク：一覧から選び、話すと緑のバーが動けば OK。授業中に切り替えても ALT との接続は切れません。
- スピーカー：Chrome / Edge では一覧から選べます。Safari では選べないので、Mac の「システム設定 → サウンド → 出力」で切り替えます。
- 「3秒録音して再生」で、マイクとスピーカーをまとめて確かめられます。
- 選んだ機器はこのパソコンのブラウザに記憶されます。見つからないときは既定の機器を使います。

## スライドの操作（PowerPoint と同じ）

| 操作 | キー |
|---|---|
| 次へ（アニメーション・次のスライド） | クリック、→、↓、Space、Enter、PageDown、N |
| 前へ | ←、↑、PageUp、Backspace、P |
| 最初から全画面／今のスライドから全画面 | F5／Shift+F5 |
| 全画面をやめる | Esc |
| 番号のスライドへ | 数字 → Enter |
| 最初／最後 | Home／End |
| 黒い画面／白い画面 | B（.）／W（,） |
| ALTにお願い（入力欄を開く） | Q または / |
| マイクON/OFF | M |
| 全画面中にALTを小さく表示 | A |

プレゼン用リモコンは PageUp/PageDown・F5・Esc・B を送るので、そのまま使えます。
全画面中にALTがボードに書いたときは、スライドの上に表示されます（次のクリックで閉じます）。

## スマホ・タブレット

スマホやタブレットのブラウザでも使えます（画面の大きさに合わせて配置が変わります）。
- 縦向き：上にスライド、下にALT。横向き：PCと同じく左にALT、右にスライド
- スライドをタップで次へ、左右にスワイプで進む／戻る
- 「全画面」中は右上のボタンで ALTの表示（🙂）・ALTにお願い（💬）・全画面をやめる（✕）
- iPhone は画面全体の全画面表示に対応していないため「⛶ 全画面」ボタンは出ません

## PowerPoint を読み込む

**最初に1回だけ**：`tools/変換係をインストール.command` をダブルクリック（「開発元が未確認」と出たら右クリック →「開く」）。
このMacに「変換係」が登録され、ログインするたびに裏で自動的に動きます。

あとは、AI-ALT のレッスン編集で「📥 PowerPoint を読み込む」から **.pptx を選ぶか、画面にドラッグする**だけ。変換係が PowerPoint で変換し、そのまま読み込まれます（PowerPoint が一瞬開いて閉じます）。

- 初めての変換で Mac から「PowerPoint を操作する」などの許可を聞かれたら「OK／許可」
- Chrome に「ローカルネットワーク上のデバイスへのアクセス」を聞かれたら「許可」
- Safari では「▶ 変換を始める」を押すと変換係の小さなウィンドウが開いて変換します（終わると閉じます）。ポップアップがブロックされたら、Safari の設定でこのサイトのポップアップを許可
- スライドがすでにあるレッスンに読み込むと「置き換える／後ろに追加」を選べます（事前に削除する必要はありません）
- 変換係をやめる：`tools/変換係をアンインストール.command`
- 記録（うまくいかないとき）：`~/Library/Logs/AI-ALT-helper.log`
- 変換係を使わない方法：`tools/スライドを変換.command` で .pptx を選ぶ → できた `○○.aialt-slides.json` を「📥 PowerPoint を読み込む」で選ぶ

- クリックごとの状態を PowerPoint 自身が描くので、見た目は元のスライドと同じです
- アニメーションは「フェード・スライドイン・ワイプ・ズーム・浮き上がり・アピア」を再現（その他はフェード）。画面切り替えはクロスフェード
- PowerPoint の**ノート**は「ALTへのメモ」になります（学生には見えません）
- **効果音・音楽も再生**：アニメーションの効果音・画面切り替えの音はそのクリック／切り替えで、スライドに貼った音声は PowerPoint の設定どおり（自動／クリック時・音量・ループ・「スライド切り替え後も再生」の枚数）に再生します
  - 再生中は画面下に「♪ 再生中 ⏹ 止める」（S キーでも止まる）
  - 音楽の再生中は教室のマイクを自動で OFF にし、終わると ON に戻します（ALT が音楽を聞き取らないように）
  - 動画は対象外。再生できない形式（WMA など）は自動で変換し、できないものは省きます
- スライドを直したら、もう一度変換して読み込み直してください
- 必要なもの：Mac・Microsoft PowerPoint・python-pptx（初回に自動インストール）・poppler（`brew install poppler`）

## レッスンの作り方

レッスン一覧 →「＋ 新しいレッスン」→ 編集画面で
- 担当ALT、学生のレベル
- **ALTへの指示**：授業の流れ・ALTの役割・台本（英語で書くと正確）
- **スライド**：本文は1行ずつ表示。`- ` で箇条書き、`**語句**` で黄色マーカー。画像・図も追加可。「ALTへのメモ」は学生には見えません

レッスンはブラウザ内に保存されます。保管・別のPCへの移動は「📤 書き出す」→「📥 読み込む」。
サンプル「Second Conditional — My Home & Neighborhood」（模擬授業用）が最初から入っています。

## 動かし方

中継サーバーが受け付けるのは `http://localhost:8765` と `https://shintaro101-tech.github.io` からのアクセスだけです。

**このPCで使う**（「名桜大学公募」フォルダで）:

```bash
python3 -m http.server 8765 --directory AI-ALT
```

→ http://localhost:8765 を Chrome で開く（マイクの許可が必要）。合言葉は洋書トークと同じです。

**ウェブ公開する**：このフォルダを GitHub Pages（shintaro101-tech.github.io のリポジトリ）に置けば、どのPCからでも開けます。
